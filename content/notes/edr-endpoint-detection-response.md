## EDR 是什么

EDR（Endpoint Detection and Response，端点检测与响应）是一种**主动式**端点安全方案。保护对象包括员工电脑、服务器、云主机、移动设备和 IoT 设备。

它与传统杀毒软件（EPP）的区别可以用一句话概括：

> 传统杀毒是「保安」，只认识通缉令上的坏人；EDR 是「私家侦探 + 特警队」，盯着端点的一举一动，连坏人踩点、掏工具的动作都能识别，出事后还能快速封锁现场、复盘反击。

## 五步工作闭环

EDR 的核心流程是「采集 → 分析 → 响应 → 溯源 → 预防」的循环：

### 1. 持续数据采集

在每台端点安装轻量级 Agent，持续采集：谁登录了、运行了什么进程、改了什么文件、访问了什么域名。所有数据经加密隧道汇总到中央数据湖。

### 2. 实时分析与检测

- **静态比对**：与威胁情报库（黑名单、特征码）实时匹配，秒杀已知威胁
- **动态分析**：通过 UEBA（用户和实体行为分析）识别反常行为

举个典型场景：一台平时只打字的财务电脑，半夜突然用管理员权限扫描其他服务器——即使没有命中任何病毒特征，这种反常行为也会被揪出来。

### 3. 自动化威胁响应

发现威胁后按预设规则秒级执行：

- **阻断隔离**：直接断开该设备网络，防止横向渗透
- **进程杀灭**：强行结束恶意进程
- **全网搜寻**：联动扫描其他终端是否中招

### 4. 深度溯源处置

安全团队基于 EDR 记录的上下文「复盘」：还原攻击链（从钓鱼邮件还是漏洞进来的）、动了哪些文件、拿了什么凭据，然后彻底清除恶意文件、恢复被篡改的配置、打上补丁。

### 5. 主动搜寻与加固

- **威胁搜寻（Threat Hunting）**：主动排雷，找出已潜伏但尚未发作的高级威胁
- **安全加固**：禁用高危服务（如 RDP）、整改弱口令、收紧防火墙策略

## 国内主流产品速览

| 产品             | 核心优势                                             |
| ---------------- | ---------------------------------------------------- |
| 微步在线 OneSEC  | 威胁情报能力极强，擅长识别新型攻击与 APT             |
| 360 数字安全 EDR | 云端全网安全大数据积累，未知威胁捕获能力强           |
| 奇安信天擎       | 大型政企、金融、公安场景落地经验丰富，管控与合规扎实 |

## 一句话总结

EPP 负责「御敌于国门之外」，混进来的就无能为力；EDR 则是「天网系统 + 重案组」——即便敌人化了妆进来，只要敢搞破坏，立刻断网、封锁、复盘、反击。
